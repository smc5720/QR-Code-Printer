# QR Code Printer

Windows용 QR 코드 생성 및 프린터 출력 데스크톱 애플리케이션입니다.

실행 시마다 **타임스탬프 기반 고유값**을 생성하고, 이를 QR 코드로 변환하여 미리보기 및 실제 프린터 출력을 지원합니다.

## 주요 기능

- **고유 QR 코드 자동 생성** - 현재 시간(마이크로초 단위)을 기반으로 중복 없는 고유값 생성
- **실시간 미리보기** - GUI에서 QR 코드 이미지를 즉시 확인
- **상단/하단 문구 추가** - QR 코드 위아래에 사용자 정의 텍스트 삽입 (여러 줄 지원)
- **프린터 직접 출력** - Windows 로컬/네트워크 프린터로 바로 출력 (Win32 API 활용)
- **프린터 자동 감지** - 시스템에 연결된 프린터 목록을 자동으로 불러오기
- **자동 업데이트** - 앱 시작 시 GitHub Releases에서 새 버전을 감지하여 자동 다운로드 및 교체

## 출력 레이아웃

```
┌─────────────────────┐
│     [상단 문구]      │  ← 선택 사항
├─────────────────────┤
│                     │
│     [QR 코드]       │
│                     │
├─────────────────────┤
│   ID: 20260412-...  │  ← 항상 표시
│   생성: 2026-04-12  │
├─────────────────────┤
│     [하단 문구]      │  ← 선택 사항
└─────────────────────┘
```

## 요구 사항

- **OS**: Windows
- **Python**: 3.x

## 설치

```bash
pip install qrcode[pil] pillow pywin32
```

## 실행

```bash
python qr_printer.py
```

## 사용 방법

1. 프로그램을 실행하면 자동으로 QR 코드가 생성됩니다.
2. 필요 시 **상단 문구** / **하단 문구**를 입력합니다. (Enter로 줄바꿈 가능, 비워두면 미출력)
3. **새 QR 생성** 버튼으로 새로운 고유값의 QR 코드를 생성할 수 있습니다.
4. 프린터를 선택한 뒤 **프린터로 출력** 버튼을 클릭하면 출력됩니다.

## 자동 업데이트

앱 시작 시 GitHub Releases의 최신 버전을 자동으로 확인합니다.

1. 새 버전이 감지되면 업데이트 여부를 묻는 팝업이 표시됩니다.
2. 승인 시 진행률 표시와 함께 자동 다운로드됩니다.
3. 다운로드 완료 후 파일을 교체하고 앱이 자동 재시작됩니다.

### 릴리즈 배포 방법 (개발자용)

새 버전을 배포할 때는 GitHub Releases에 태그를 생성하고 에셋을 업로드합니다.

```bash
# 예: v1.1.0 릴리즈
git tag v1.1.0
git push origin v1.1.0
```

그런 다음 GitHub Releases 페이지에서:
- `.py` 배포 시: `qr_printer.py` 파일을 에셋으로 업로드
- `.exe` 배포 시: PyInstaller로 빌드한 exe 파일을 에셋으로 업로드

> 코드 내 `VERSION` 상수를 릴리즈 태그와 일치시켜야 합니다.

## 기술 스택

| 구분 | 기술 |
|------|------|
| GUI | Tkinter |
| QR 코드 생성 | qrcode + Pillow |
| 프린터 제어 | pywin32 (win32print, win32ui) |
| 자동 업데이트 | GitHub Releases API + urllib |
| 폰트 | 맑은 고딕 (기본), Arial, Consolas 순서로 폴백 |
