# QR Code Printer

Windows용 QR 코드 생성 및 프린터 출력 데스크톱 애플리케이션입니다.

시간 기반 **Base36 고유값**(10자, 예: `HHK7JCTL6N`)을 생성하여 QR 코드로 변환하고, 미리보기 및 프린터 출력을 지원합니다. 상품 라벨링처럼 QR이 고유 식별자로 쓰이는 용도에 맞춰 **중복 출력 방지** 장치도 포함되어 있습니다.

## 주요 기능

- **Base36 고유값** — epoch 마이크로초를 대문자 Base36으로 인코딩해 10자 고유 ID 생성 (2085년까지 10자 유지)
- **실시간 미리보기** — 문구·폰트·방향 변경이 즉시 반영
- **상단/하단 문구** — QR 위아래에 여러 줄 텍스트 삽입 (폰트 패밀리/크기/굵기 선택)
- **출력 방향** — 세로/가로 선택
- **수량 지정** — 1~999매를 하나의 인쇄 작업으로 전송
- **중복 출력 방지**
  - 출력 후 경고 배너 표시 (`⚠ 이미 N매 출력됨 · 경과 시간`)
  - 출력 버튼이 `추가 출력` 으로 바뀌고 회색화, 재출력 시 확인 다이얼로그
  - `새 QR 생성` 버튼이 파란색으로 강조 전환
- **출력 이력 영속화** — 최근 20건의 ID/매수/시각을 저장, 팝업에서 과거 QR 선택하여 **재출력 가능** (더블클릭 또는 버튼)
- **프린터 자동 감지** — 로컬/네트워크 프린터 목록 자동 로드
- **설정 캐시** — 문구·폰트·방향·이력이 `%LOCALAPPDATA%\QR-Code-Printer\qr_printer_config.json` 에 저장되어 재실행 시 복원
- **자동 업데이트** — 앱 시작 시 GitHub Releases에서 새 버전 확인 → 진행률 표시 → 파일 교체 후 재시작

## 출력 레이아웃

```
┌─────────────────────┐
│     [상단 문구]      │  ← 선택 사항
├─────────────────────┤
│                     │
│     [QR 코드]       │
│                     │
├─────────────────────┤
│   ID: HHK7JCTL6N    │  ← 10자 Base36
├─────────────────────┤
│     [하단 문구]      │  ← 선택 사항
└─────────────────────┘
```

## 다운로드

[최신 버전 다운로드 (Releases)](https://github.com/smc5720/QR-Code-Printer/releases/latest)

- **QR-Code-Printer.exe** — Python 설치 없이 바로 실행 가능
- **qr_printer.py** — Python 환경에서 직접 실행

## 요구 사항

- **OS**: Windows
- **Python**: 3.12 권장 (PyInstaller 호환성)

## 설치

```bash
pip install qrcode[pil] pillow pywin32
```

## 실행

```bash
python qr_printer.py
```

## 사용 방법

1. 프로그램을 실행하면 자동으로 새 QR 코드가 생성됩니다.
2. 필요 시 **상단 문구** / **하단 문구**를 입력합니다. (Enter로 줄바꿈, 비워두면 미출력)
3. 프린터와 **출력 방향**(세로/가로), **수량**을 지정합니다.
4. **프린터로 출력** 버튼을 클릭합니다.
5. 출력 성공 후 화면이 "이미 출력됨" 상태로 전환됩니다.
   - 같은 상품에 **추가로** 붙이려면 `추가 출력` 클릭 → 확인 후 인쇄
   - 다른 상품으로 넘어갈 땐 반드시 `⟳ 새 QR 생성` 클릭 (수량도 1로 초기화)
6. **이력 보기** 버튼으로 최근 20건 팝업을 열고, 과거 QR을 선택해 재출력할 수 있습니다.

## 자동 업데이트

앱 시작 시 GitHub Releases의 최신 버전을 백그라운드에서 1회 확인합니다.

1. 새 버전이 감지되면 업데이트 여부를 묻는 팝업이 표시됩니다.
2. 승인 시 진행률 표시와 함께 자동 다운로드됩니다.
3. 다운로드 완료 후 파일을 교체하고 앱이 자동 재시작됩니다.
   - `.exe` 실행 시: 배치 스크립트를 통해 자체 교체
   - `.py` 실행 시: 파일 직접 교체 후 재실행

### 릴리즈 배포 방법 (개발자용)

새 버전을 배포할 때는 `qr_printer.py` 의 `VERSION` 상수를 수정한 후 태그를 푸시합니다.
GitHub Actions가 자동으로 `.exe` 를 빌드하고 릴리즈를 생성합니다.

```bash
# 예: v1.8.0 릴리즈
git tag v1.8.0
git push origin v1.8.0
```

> `VERSION` 상수를 릴리즈 태그와 일치시켜야 합니다. (`release.sh` 스크립트로 자동화 가능)
